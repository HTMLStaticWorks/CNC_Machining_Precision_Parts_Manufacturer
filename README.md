# Forgea — Precision Manufacturing Website

A complete responsive multi-page front-end website concept based on the supplied manufacturing website brief.

## Included
- Home 1 and Home 2
- About
- Products
- CNC Milling
- CNC Turning
- Prototyping & Engineering
- Contact / Request Quote
- Client Login
- Client Signup
- Client Dashboard
- Shared responsive header/footer
- Desktop/tablet/mobile layouts
- CSS-only visual system with remote placeholder imagery
- Demo form interactions and dashboard navigation

## Run
Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Important
This is a front-end prototype. Login, signup, CAD upload, quotes, orders, invoices and dashboard data are demo UI and need a backend/auth/storage system before production.

The site now uses real CNC/manufacturing photography from free-use Unsplash/Pexels image pages. Replace the remote URLs with locally hosted licensed/generated assets if you want a fully offline package.
